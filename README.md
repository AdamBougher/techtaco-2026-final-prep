# VS Code in GitHub: Follow-Along Tutorial

This repository is a hands-on tutorial workspace for learning how to use
Visual Studio Code in GitHub.

## Getting started

1. Open this repository on GitHub.
2. Press the `.` (period) key from the repository page to open it in
   [github.dev](https://docs.github.com/en/codespaces/the-githubdev-web-based-editor).
3. Alternatively, open **Code → Codespaces → Create codespace on main** for a
   full development environment.

## What to try

- Use the **Explorer** to browse and open files.
- Use the Command Palette (`Ctrl/Cmd+Shift+P`) to find VS Code commands.
- Edit this README and use **Preview** to see the Markdown result.
- Open a terminal and run `git status` to inspect repository changes.
- Explore Git changes in the Source Control view.
- Use extensions to add support for the language or tools you want to use.
